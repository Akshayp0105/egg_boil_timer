# 🥚 Egg Boiling Timer – Full Stack Web App

A professional, high-performance web application designed to help users achieve the perfect egg consistency through scientific timing. This project features a modern React interface, a robust Node.js backend, and a dynamic theming engine.

### 🔗 [Live Demo](https://egg-boil-timer-silk.vercel.app/)

---

## 🚀 Features

* **Precision Timing:** Preset modes for Soft, Medium, and Hard-boiled eggs.
* **Dynamic Theming:** Seamlessly switch between UI themes with persistent state.
* **Audio Alerts:** Integrated sound notifications for timer completion.
* **Statistics Tracking:** Backend-integrated tracking to monitor cooking habits.
* **Real-time Sync:** Reliable state management between the frontend and backend API.

---

## 🛠 Tech Stack

**Frontend:**
* **React (Vite)** – Fast, modern component-based UI.
* **CSS3 / Styled Components** – Advanced animations and dynamic theming.
* **Lucide React** – For clean, scalable iconography.

**Backend:**
* **Node.js & Express** – Scalable server-side logic and RESTful API.
* **CORS & Middleware** – Secure communication between origins.

**Deployment:**
* **Frontend:** Vercel
* **Backend:** Render

## 🏗 Installation & Setup

### 1. Clone the repository
```bash
git clone [https://github.com/YOUR_USERNAME/egg-boil-timer.git](https://github.com/YOUR_USERNAME/egg-boil-timer.git)
cd egg-boil-timer
```
## 2. Backend Setup

Bash
cd backend
npm install
npm start

## 3. Frontend Setup

Bash
cd frontend
npm install
npm run dev
