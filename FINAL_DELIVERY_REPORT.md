## 🎓 How to Use

### Quick Start (5 minutes)
1. **Run startup script**
   - Windows: `quick-start.bat`
   - Mac/Linux: `bash quick-start.sh`

2. **Open browser**
   - Go to `http://localhost:5175`

3. **Enjoy!**
   - Click timer level and watch it boil

### Full Setup (10 minutes)
1. **Install dependencies**
   ```bash
   cd egg && npm install
   cd ../backend && npm install
   ```

2. **Start servers** (in 2 terminals)
   ```bash
   # Terminal 1
   cd egg && npm run dev
   
   # Terminal 2
   cd backend && npm start
   ```

3. **Open app**
   - http://localhost:5175

### Production Deployment (varies by platform)
1. Read `DEPLOYMENT_GUIDE.md`
2. Choose platform (Vercel, Heroku, etc.)
3. Follow instructions
4. Deploy!
